- [Bugfix] Use the Indigo favicon everywhere. Legacy MFEs now point `FAVICON_URL` at the theme's `favicon.ico`, because the LMS `/favicon.ico` URL redirects to the platform default instead, and their build sets `FAVICON_URL` so that the `index.html` they ship has a favicon link before any JavaScript runs. The frontend-base site uses the Indigo favicon instead of the placeholder from `@edx/brand`. (by @arbirali)
