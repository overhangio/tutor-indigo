- [Feature] Add a per-user dynamic theme: learners can pick a Light or Dark appearance preset and personalize five core Paragon colours (primary, primary light, secondary, text and info) from a new theme settings block in the Profile Information section of the Account MFE. The appearance preset is saved as soon as it is picked, while colour changes are previewed live and stored with the "Save" button. While the feature is enabled the header light/dark toggle is hidden, since the appearance preset replaces it. Choices are stored per user by the new `indigo_theme` Django app, which is installed into the `openedx` image and serves them from `/api/indigo/v1/theme/`. Legacy LMS pages and the courseware unit iframe, whose stylesheets are compiled from SASS with literal colours, are retinted at runtime by a new theme script. The feature is controlled by the new `INDIGO_ENABLE_DYNAMIC_THEME` setting (default: True). (by @HammadYousaf01)
