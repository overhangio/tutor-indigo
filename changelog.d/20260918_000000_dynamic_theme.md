- [Feature] Add a per-user dynamic theme: learners can pick a Light or Dark appearance preset and personalize five core Paragon colours from a new theme settings block in the Profile Information section of the Account MFE. The appearance preset is saved as soon as it is picked, while colour changes are previewed live and stored with the "Save" button; colours that would be unreadable against the page background are rejected. The header light/dark toggle stays available and is kept in sync with the appearance preset, in both directions. Choices are stored per user by the new `indigo_theme` Django app, which ships with this plugin, is installed into the `openedx` image from the build context, and serves them from `/api/indigo/v1/theme/`. Legacy LMS pages and the courseware unit iframe, whose stylesheets are compiled from SASS with literal colours, are retinted at runtime by a new theme script. The feature is controlled by the new `INDIGO_ENABLE_DYNAMIC_THEME` setting (default: True), and only colours a learner has actually chosen are applied, so sites with their own brand CSS are unaffected until a learner customizes something.
