- [Improvement] Stop installing the `@edx/brand` package into every MFE image. Indigo's compiled stylesheets are now delivered to the MFEs as URLs, through `PARAGON_THEME_URLS` and the frontend-base site theme, which is what those settings are for. The same files reach the browser, so the theme is unchanged, but MFE images no longer need to reach GitHub to build. (by @HammadYousaf01)
- [Bugfix] Fetch the MFE stylesheets from a URL the browser will actually accept. The previous `raw.githubusercontent.com` URLs were served as `text/plain` with `nosniff`, so every one of them was blocked by the browser and silently fell back to the bundled copy. (by @HammadYousaf01)
